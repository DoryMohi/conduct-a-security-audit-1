# Botium Toys – Security Audit & Recommendations

## 📌 Project Overview
This project presents a security audit conducted for **Botium Toys**, focusing on evaluating the organization’s current security posture, identifying gaps in controls and compliance, and providing actionable recommendations to reduce risk and improve overall security maturity.

The audit is based on asset management, risk assessment, and alignment with industry best practices such as **NIST CSF**, **GDPR**, and **SOC (Type 1 & Type 2)**.

---

## 🎯 Audit Scope and Goals

### Scope
The scope of this audit includes the **entire security program** at Botium Toys, covering:
- Employee equipment and end-user devices
- Internal network and internet access
- Systems, software, and services (ecommerce, database, accounting, security, inventory)
- Data retention and storage
- Legacy systems
- Physical assets (offices, storefront, warehouse)

### Goals
- Identify and assess existing assets
- Evaluate implemented security controls
- Review compliance with regulatory and industry standards
- Identify control gaps and risks
- Provide recommendations to improve security posture

---

## 📊 Risk Assessment Summary

- **Primary Risk:** Inadequate asset management and missing security controls
- **Risk Score:** 8 / 10 (High)
- **Key Issues Identified:**
  - Excessive user access to sensitive data
  - No encryption for customer credit card data
  - Lack of least privilege and separation of duties
  - No IDS, backups, or disaster recovery plan
  - Weak password policy and no centralized password management
  - Incomplete legacy system maintenance processes

---

## 🔍 Key Findings

### Controls Implemented (Yes)
- Firewall with defined security rules
- Antivirus software (installed and monitored)
- Physical security controls (locks, CCTV)
- Fire detection and prevention systems
- Data availability and integrity controls
- GDPR breach notification plan (72-hour rule)
- Enforced privacy policies and procedures

### Controls Missing or Inadequate (No)
- Least privilege
- Separation of duties
- Encryption of sensitive data
- Intrusion Detection System (IDS)
- Backups and disaster recovery plan
- Centralized password management system
- Strong password policy enforcement
- Formal asset classification and inventory
- Regular legacy system maintenance schedule

---

## 🛠️ Recommendations

### 1. Asset Management
- Create a centralized inventory of all hardware, software, and data assets
- Assign asset ownership and classify assets based on sensitivity

### 2. Access Control
- Implement least privilege and role-based access control (RBAC)
- Enforce separation of duties
- Restrict access to PII, SPII, and cardholder data

### 3. Data Protection
- Encrypt sensitive data at rest and in transit using industry standards
- Protect customer credit card and personal information

### 4. Identity & Password Management
- Strengthen password complexity requirements
- Implement a centralized password management system

### 5. Monitoring & Detection
- Deploy an Intrusion Detection System (IDS)
- Implement a SIEM solution for centralized log monitoring and alerting

### 6. Backup & Disaster Recovery
- Perform regular backups of critical data
- Develop and test a disaster recovery plan

### 7. Legacy Systems
- Establish a defined monitoring and maintenance schedule
- Document intervention and escalation procedures

### 8. Continuous Compliance
- Conduct regular internal audits
- Schedule periodic external audits
- Review and update security policies regularly
